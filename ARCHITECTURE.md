# Архитектура

- React Router переключает страницы прогноза, анализа спроса, цен и сценариев. TanStack Query загружает JSON. Recharts отображает квантильные точки и расчёты цен.
- FastAPI читает данные при запуске. Pandas проверяет схему, числовые значения, уникальность, сетку дат и порядок квантилей. Ошибка чтения возвращается как HTTP 503. Для новой версии CSV перезапустите сервис. Версия определяется по SHA-256 обоих файлов.
- Для каждого квантиля сервер вычитает из базового спроса произведение чувствительности маршрута на изменение цены. Продажи ограничены нулём и вместимостью. Выручка равна цене, умноженной на продажи. Медиана берётся из той же коллекции точек, которая передаётся графику. Линейный спрос сохраняется без обрезки. Интерфейс отображает пассажиров и билеты до десятых, рубли до целых, проценты до десятых.
- SQLAlchemy хранит пользователей, сессии и сохранённые расчёты в SQLite или PostgreSQL. Argon2 хеширует пароли. В базе хранится хеш случайного токена сессии. Cookie HttpOnly имеет срок действия семь дней. Для HTTPS включается Secure. Изменяющие аккаунт и сценарии запросы требуют нестандартный заголовок. Приложение работает на одном домене без разрешённых сторонних CORS origins. Вход ограничен восемью попытками с IP за десять минут. Сценарии фильтруются по владельцу.
- Сценарий хранит снимок расчёта и версию данных. При открытии сервер рассчитывает текущие значения и разницу со снимком.
