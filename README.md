# GOLUBKA AVIA · Demand Intelligence

Веб-приложение для конкурсного задания «Динамическое ценообразование авиабилетов», вариант C. Поддерживает пять маршрутов и даты с 1 июня по 1 июля 2026 включительно. Спрос, продажи, выручку и квантили рассчитывает FastAPI. React отображает результат. Основная аналитика доступна без аккаунта.

## Запуск

С Docker из корня проекта:

```sh
docker compose up --build
```

Откройте http://127.0.0.1:8000. SQLite хранится в томе `state`.

Без Docker нужны Python 3.12, Node.js 24 и pnpm 11.25.0:

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
(cd frontend && pnpm install --frozen-lockfile && pnpm build)
cd backend
../.venv/bin/python -m uvicorn app.main:app --port 8000
```

API и интерфейс доступны по тому же адресу. Для разработки можно запустить `pnpm dev` в папке frontend параллельно с API. Vite проксирует запросы API на порт 8000.

## Данные

`data/my_forecast.csv` — приложенный итоговый прогноз из ML-блока. `data/routes.csv` — параметры из ссылки в конкурсном PDF. Набор содержит 155 строк прогноза, 30 столбцов и девять квантилей. Для пересчёта применяются только базовые значения спроса и параметры маршрута. Рекомендации ML отображаются с указанием сценария.

## Дизайн GOLUBKA AVIA

Главная, Pricing Lab и сохранённые сценарии оформлены в общей палитре. Авиационные иллюстрации в WebP находятся в `frontend/public`. Для таблицы рекомендаций API дополнительно возвращает базовый спрос и продажи по каждому квантилю. В финансовом сравнении прибыль по модели считается как выручка за вычетом переменных затрат на пассажира.

В сохранённых сценариях доступны поиск, фильтры маршрутов и дат и избранное. При первом запуске сервер создаёт отдельную таблицу избранного для существующей базы.
