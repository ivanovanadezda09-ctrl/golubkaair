Повторить:

```sh
.venv/bin/pip install -r backend/requirements-test.txt
(cd backend && ../.venv/bin/python -m pytest -q)
(cd frontend && pnpm test)
```

Для Playwright запустите локальный сервер с отдельной временной SQLite через `DATABASE_URL`. Тест регистрации создаёт временный аккаунт. Затем выполните:

```sh
cd frontend
pnpm exec playwright install chromium
BASE_URL=http://127.0.0.1:8000 pnpm e2e
```

С установленным Google Chrome можно вместо установки Chromium указать `CHROME_CHANNEL=chrome`.
