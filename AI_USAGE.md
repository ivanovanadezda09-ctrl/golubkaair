# Использование ИИ

OpenAI Codex на базе GPT‑6 использовался для чтения ТЗ, проектирования, написания React и FastAPI, проверки данных, тестов и документации. Команды запуска и браузерные тесты выполнялись локально. Сам сервис рассчитывает спрос по конкурсной формуле и использует приложенный прогноз из ML-блока.
